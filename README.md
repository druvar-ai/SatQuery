# SatQuery

**A Multi-Spacecraft, Multi-Modal AI Mission Intelligence Platform for Space Observation**

## Overview
SatQuery simulates multi-spacecraft mission operations and autonomously plans observation opportunities across configurable celestial environments (Earth, Moon, Mars). It incorporates an AI-driven observation-analysis layer using local synthetic imagery to demonstrate automated intelligence extraction and multimodal fusion for simulated space missions.

**IMPORTANT:** SatQuery does not control real satellites, nor does it perform live telemetry tracking. All orbital propagation is simulated, and AI inferences are executed on baseline heuristic synthetic data.

## Features
- **Body-Agnostic Core**: Supports Earth, Moon, and Mars.
- **Configurable N Spacecraft**: Simulate anywhere from 1 to 100+ spacecraft concurrently.
- **Observation Planning**: Ranks observation opportunities for target regions based on visibility and geometry.
- **SatQuery AI**: Natural language query engine over simulated optical and SAR observation data.
- **API Foundation**: FastAPI backend for mission control and state queries.
- **Streamlit Mission Control**: Modern, unified dashboard for viewing operations, planning missions, and running AI intelligence queries.
- **Blender Export**: Streams simulation state to JSON for 3D visualization inside Blender.

## QUICK START

### 1. Create Environment & Install Dependencies
**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```
**WSL / Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Start the API
```bash
uvicorn satquery.backend.api.main:app
```
*(Leave this running in the background)*

### 3. Run the Demo Setup
In a new terminal window (with the venv activated):
```bash
python scripts/demo_setup.py
```

### 4. Start the Streamlit Mission Control
```bash
streamlit run frontend/app.py
```

### 5. (Optional) Start Blender 3D Visualization
1. Open Blender.
2. Ensure you have objects named `earth`, `sat-0`, `sat-1`, ..., `sat-9`.
3. Open the Scripting workspace.
4. Open and run `scripts/blender_importer.py`.

## JUDGE DEMO — 3 MINUTES

1. **Open SatQuery Mission Control** via Streamlit (`http://localhost:8501`).
2. **Navigate to Overview:** Show the 10-spacecraft constellation generated by the setup script and point out the live simulation clock.
3. **Navigate to Mission Planning:** 
   - Select Earth.
   - Enter a target coordinate (e.g., Lat: 0.0, Lon: 0.0).
   - Click "Calculate Visibility Windows" to show why the selected spacecraft is best based on geometry and sensor.
4. **Navigate to SatQuery AI:**
   - Select the newly planned observation from the dropdown.
   - Ask: *"What is present in this observation?"*
   - Show the resulting Routing Trace (demonstrating model selection), Evidence list, and calibrated Confidence score.
5. **Demonstrate Change Detection:**
   - Ask: *"What changed?"*
   - Show the BEFORE / AFTER / CHANGE MASK results.
6. **Multi-Body Capability:**
   - Return to Mission Planning.
   - Switch to **Moon** or **Mars** to explain that the identical architecture manages spacecraft on those bodies without hardcoded logic.

## Architecture
- `satquery/backend/`: Core orbital propagation, API, and AI analysis pipelines.
- `frontend/`: Streamlit Mission Control dashboard.
- `scripts/`: Judge setup utilities and Blender importer scripts.
- `tests/`: Extensive automated verification suite (`pytest tests/`).
